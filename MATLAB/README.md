# import_frenate_da_telemetria #

MATLAB script developed to import from Motec i2 Pro telemtry data directly into the MATLAB workspace, chance to use Simulink pre-set block 'from workspace' to improve simulation time.

# script_tracciato_austria #

MATLAB script used to import from GPS data the coordinates of the track we wanted to simulate the lap time.

# dati_ #

Simple MATLAB script developed just to create clear plots to insert in the design presentation for the design events


## HOW TO USE THEM

* Download the MATLAB folder
* Be sure every MATLAB script and the linked Excel file are in this folder
* Open the one yu want to simulate and click run
